# cs2c-bridge

Connects a CS2C custody model, written in Python, to the CS2C Custody Visualizer.

```bash
pip install -e ./bridge          # from the repo root; needs Python 3.9+
python -m cs2c_bridge            # stand-in demo model on ws://127.0.0.1:8765
```

In the visualizer: **Custody selection → CS2C → Connect**. See the repo README and `docs/protocol.md`.
